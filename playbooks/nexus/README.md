# Cisco Nexus Playbooks

This directory will contain Cisco Nexus/NX-OS network automation, including:

- Read-only facts and configuration backup
- VLANs and interfaces
- Port-channels and vPC
- VRFs and routing prerequisites
- Controlled configuration deployment and verification

Use `network_cli` or `httpapi` according to the switch version and lab
standard. Start with facts and backups before applying configuration.
